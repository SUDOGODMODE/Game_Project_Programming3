Der **aktuelle Kurs endet mit Meilenstein 6**; dessen gesonderter Auftrag ist
inzwischen lokal umgesetzt und geprüft, siehe
[M6-Anforderungsabgleich](status/06_requirements.md). Die ältere Datei
`assignments/project_flow.txt` und darauf aufbauende alte Statusdokumente
verwenden eine andere Folge bis M8. Sie bleiben als historische Unterlagen
erhalten und bestimmen keine neue Aufgabe.

`evidence/` enthält unveränderte Rohbelege und frühere Läufe. Ein alter
Testbericht beschreibt nur den damaligen Stand. Neue Berichte erhalten
einen neuen Pfad; das aktuelle Ergebnis steht in `WEITERARBEITEN.md`.
