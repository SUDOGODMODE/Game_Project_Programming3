Rohausgabe von server.py, client.py und test_angriff.py
==========================================================

Real ausgefuehrt am 22.09.2026, drei getrennte Sitzungen, jeweils gegen
einen frisch gestarteten Server. Hinweis zum Port: der committete Code
verwendet wie vorgegeben Port 5000; auf diesem Testrechner (macOS) belegt
der AirPlay-Empfaenger Port 5000 dauerhaft, deshalb zeigt diese Ausgabe
Port 5095 als lokalen Ersatz. Interpretation und Kriterien-Tabelle stehen
in 01_client_server_output.md.

===== Testlauf 1: einzelner Beitritt =====
$ python3 src/client.py
  -> {'type': 'join', 'player': 'Alice'}
  <- {'type': 'welcome', 'slot': 'A', 'player': 'Alice', 'phase': 'waiting'}
--- Server-Terminal ---
Server wartet auf Port 5095
verbunden: ('127.0.0.1', 50100)
  <- [('127.0.0.1', 50100)] {'type': 'join', 'player': 'Alice'}
  -> [('127.0.0.1', 50100)] {'type': 'welcome', 'slot': 'A', 'player': 'Alice', 'phase': 'waiting'}
getrennt: ('127.0.0.1', 50100)
