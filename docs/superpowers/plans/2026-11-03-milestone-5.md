# Kursmeilenstein 5 Implementation Plan

> **For agentic workers:** Required workflow: test first, implementation second, independent review. No staging, commits, pushes or GitHub changes in this project.

**Goal:** Die Anforderungen des neuen Kursmeilensteins 5 für Schiffe versenken lokal umsetzen und wahrheitsgemäss belegen.

**Architecture:** `spiel.py` ist die einzige Regelquelle; `board.py` bleibt ein schmaler Kompatibilitätseinstieg. Der Server delegiert Spielaktionen und sendet nach dem letzten Schuss zuerst beide individuellen Zustände, dann beiden Spielern die Endnachricht.

**Tech Stack:** Python 3.12+, unittest, tkinter, TCP, Standardbibliothek.

**Spec:** `docs/superpowers/specs/2026-11-03-milestone-5-design.md`

## Global Constraints

- Nur Kursmeilenstein 5. Bestehende Regeln und ältere Rohbelege erhalten.
- Keine Git-Schreiboperationen. Keine fremden Geräte oder Personen behaupten.
- Originalauftrag, `REGELN.md` und Protokollinhalt bleiben nachvollziehbar.

## Review Focus

- Ein Schuss nach Spielende muss privat abgelehnt werden und darf keinen Zustand verändern.
- Ein Endzustand muss an **beide** gehen, bevor **beide** `gameOver` erhalten.
- Versteckte Schiffe dürfen auch im letzten Zustand nicht an den Gegner gehen.
- Ein boolescher oder anders falsch typisierter Schuss darf kein Feld treffen.
- Ein Reset nach Verbindungsende darf keine alte Endmeldung stehen lassen.
