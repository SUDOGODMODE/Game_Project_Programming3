# Strukturbegriffe

- **Kurseinstieg:** stabiler Dateipfad und Befehl für Spiel, Server, Client
  oder Kurstest. Er bleibt beim Umordnen erhalten.
- **Internes GUI-Modul:** Baustein für Brettzeichen, Canvas-Feld, SVG oder
  Effekt. Er liegt in `src/gui/` und wird vom GUI-Einstieg importiert.
- **Zusatzprüfung:** bestehender Test für Logging oder Abgabepakete ohne
  eigene Kursmeilensteinnummer. Der Gesamtlauf sammelt sie weiterhin.
- **Historischer Nachweis:** alte Aufgabe oder Rohdatei unter `docs/` mit
  damaliger Nummerierung. Sein Inhalt und Pfad bleiben unverändert.
